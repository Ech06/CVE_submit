# Vuln: GPAC MP4Box Heap Use-After-Free in `gf_node_changed_internal`

**Project:** GPAC (https://github.com/gpac/gpac)  
**Version:** Vulnerable at commit `f1219cde1a892a913ec85d7fd97324ece94c2d15`, fixed by commit `9eb40df4448b88d6a6ce3454657c06f47eff0b24`  
**Date:** 2026-07-27  
**Severity:** HIGH  
**OWASP:** N/A - Native File Parsing Memory Corruption  
**CWE:** CWE-416 - Use After Free  

---

## Affected File

```text
src/scenegraph/base_scenegraph.c (`gf_node_replace`, `gf_node_changed_internal`)
src/compositor/scene.c (scene teardown path)
src/filters/compose.c (filter finalization path)
```

## Root Cause

During teardown of a malformed scene graph, `gf_node_replace()` unregisters the old node before notifying its parent with `gf_node_changed()`. Unregistering can destroy the node and related prototype state. The subsequent notification traverses scene-graph state that already contains freed memory, leading to a heap-use-after-free read in `gf_node_changed_internal()`.

The upstream fix changes the operation order so the parent is notified while the old node is still valid:

```diff
 if (new_node && new_node != par) gf_node_register(new_node, par);
-gf_node_unregister(node, par);
 if (node != par)
     gf_node_changed(par, NULL);
+gf_node_unregister(node, par);
```

## Steps to Reproduce

The following commands assume that this report's `pocs` directory is next to the cloned `gpac` directory:

```bash
git clone https://github.com/gpac/gpac.git gpac
cd gpac
git checkout f1219cde
./configure --enable-sanitizer --static-mp4box
make -j"$(nproc)"
./bin/gcc/MP4Box -add ../pocs/poc_3800 -new /tmp/out.mp4
```

## Impact

A crafted scene file can corrupt scene-graph lifetime state and crash `MP4Box` during cleanup. The defect is reachable through normal `-add` processing, so services and batch workflows that import untrusted scene descriptions can be denied service. As a heap-use-after-free, the issue may have more severe memory-corruption consequences in some execution contexts.

## Recommended Fix

Apply upstream commit `9eb40df4448b88d6a6ce3454657c06f47eff0b24` or upgrade to a later GPAC revision. The fix ensures change propagation occurs before the replaced node is unregistered and potentially freed.

Regression coverage should exercise malformed scene teardown under AddressSanitizer, not only the initial parsing phase.
