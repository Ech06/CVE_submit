# Vuln: GPAC MP4Box Invalid Child-List Read in `gf_node_list_get_child`

**Project:** GPAC (https://github.com/gpac/gpac)  
**Version:** Vulnerable at commit `f1219cde1a892a913ec85d7fd97324ece94c2d15`, fixed by commit `afca1f1181668d85941d51ed1adf647807d5d975`  
**Date:** 2026-07-27  
**Severity:** MEDIUM  
**OWASP:** N/A - Native File Parsing Memory Safety  
**CWE:** CWE-476 - NULL Pointer Dereference  

---

## Affected File

```text
src/scene_manager/loader_bt.c (`gf_bt_parse_bifs_command`)
src/scenegraph/base_scenegraph.c (`gf_node_list_get_child`)
applications/mp4box/fileimport.c (trigger path through MP4Box -add)
```

## Root Cause

While parsing a malformed indexed BIFS command, `gf_bt_parse_bifs_command()` treats the selected target field as a child-node list without first confirming that the field is the `children` field. It passes an invalid list pointer to `gf_node_list_get_child()`, which dereferences an address near NULL (`0x8`).

The upstream fix initializes `childNode`, only performs the list lookup for the `children` field, and rejects the command if no valid child is found:

```diff
-childNode = gf_node_list_get_child(*(GF_ChildNodeItem **)targetField.far_ptr, apos);
+if (!strcmp(targetField.name, "children"))
+    childNode = gf_node_list_get_child(*(GF_ChildNodeItem **)targetField.far_ptr, apos);
 if (!childNode)
     return gf_bt_report(parser, GF_BAD_PARAM,
                         "Cannot find child node at specified index");
```

## Steps to Reproduce

The following commands assume that this report's `pocs` directory is next to the cloned `gpac` directory:

```bash
git clone https://github.com/gpac/gpac.git gpac
cd gpac
git checkout f1219cde
./configure --enable-sanitizer --static-mp4box
make -j"$(nproc)"
./bin/gcc/MP4Box -add ../pocs/poc_3802 -new /tmp/out.mp4
```

Expected result on the vulnerable commit:

## Impact

A crafted BT/BIFS scene can crash `MP4Box` during import, resulting in denial of service. Any application that exposes GPAC's affected BIFS scene parsing path to untrusted input can be terminated by the malformed command.

## Recommended Fix

Apply upstream commit `afca1f1181668d85941d51ed1adf647807d5d975` or upgrade to a later GPAC revision. The patch validates the target field before interpreting it as a child-node list and returns a parser error for invalid input.

Add indexed commands targeting non-child fields and out-of-range child indexes to malformed-input regression coverage.
