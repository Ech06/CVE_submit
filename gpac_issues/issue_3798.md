**Summary**
`MP4Box -add` of a crafted BT/BIFS scene dereferences a NULL pointer inside
`gf_bt_report` (`scene_manager/loader_bt.c:126`) while formatting an error
message, reached from `gf_bt_parse_bifs_command`. The scene graph is loaded
from untrusted input without validating node state, so a malformed BIFS command
reaches the reporting path with an invalid pointer. This is a NULL-pointer
dereference / SEGV reachable with the default `-add` invocation.

**Affected Version**
gpac `f1219cde` (master, 2026-07-25), `26.08-DEV-rev5-gf1219cde-master`.

**Reproduction**
```
MP4Box -add poc_01_add -new /tmp/out.mp4
```
