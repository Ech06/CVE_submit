**Summary**
`MP4Box -add` of a crafted XMT scene triggers a heap-use-after-free READ in
`gf_sg_script_load` (`scenegraph/vrml_tools.c:265`), reached from
`gf_sg_command_apply` ← `ctxload_process`. A previously freed script node is
accessed when applying a scene command on malformed input. Reachable with the
default `-add` invocation. This issue may be an incomplete fix for https://github.com/gpac/gpac/issues/3647

**Affected Version:** gpac `f1219cde` (master, 2026-07-25).

**Reproduction**
```
MP4Box -add poc_02_add -new /tmp/out.mp4
```
