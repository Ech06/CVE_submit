**Summary**
`MP4Box -add` of a malformed scene triggers a heap-use-after-free READ in
`gf_node_changed_internal` (`scenegraph/base_scenegraph.c:1892`) during
scenegraph teardown (`gf_sg_reset` ← `gf_scene_disconnect` ← `gf_odm_disconnect`).
A freed node is touched on the reset path when the input built an inconsistent
scene graph. Reachable with the default `-add` invocation. This issue may be an incomplete fix for https://github.com/gpac/gpac/commit/5e620eff3bea16972dd948b2a153e416ffb1c81d

**Affected Version:** gpac `f1219cde` (master, 2026-07-25).

**Reproduction**
```
MP4Box -add poc_03_add -new /tmp/out.mp4
```
