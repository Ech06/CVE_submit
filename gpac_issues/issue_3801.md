**Summary**
`MP4Box -add` of a malformed scene triggers a heap-use-after-free READ in
`gf_node_unregister` (`scenegraph/base_scenegraph.c:779`), reached from
`gf_sg_vrml_parent_destroy` ← `OrderedGroup_Del` during node deletion. An
OrderedGroup child list references freed memory on the teardown path.
This issue may be an incomplete fix for https://github.com/gpac/gpac/commit/41ce91ded3aad83ca7139bd00e3ee9ff4cd7796a

**Affected Version:** gpac `f1219cde` (master, 2026-07-25).

**Reproduction**
```
MP4Box -add poc_04_add -new /tmp/out.mp4
```
