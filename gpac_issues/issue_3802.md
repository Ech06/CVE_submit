**Summary**
`MP4Box -add` of a crafted BT scene dereferences an invalid pointer in
`gf_node_list_get_child` (`scenegraph/base_scenegraph.c:1491`), reached from
`gf_bt_parse_bifs_command` (`scene_manager/loader_bt.c:2358`). A BIFS command
references a child node that is NULL/invalid. SEGV reachable with the default
`-add` invocation.
This issue may be an incomplete fix for https://github.com/gpac/gpac/issues/3768

**Affected Version:** gpac `f1219cde` (master, 2026-07-25).

**Reproduction**
```
MP4Box -add poc_05_add -new /tmp/out.mp4
```
