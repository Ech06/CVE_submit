**Summary**
`MP4Box -add` (also `-info`) of a crafted BT scene triggers a heap-use-after-free
READ in `gf_node_get_name` (`scenegraph/base_scenegraph.c:1340`), reached from
`gf_bt_has_been_def` (`scene_manager/loader_bt.c:1257`). A previously freed node
is queried for its name during DEF/USE resolution. Reachable with the default
invocation.
This issue may be an incomplete fix for https://github.com/gpac/gpac/issues/3642

**Affected Version:** gpac `f1219cde` (master, 2026-07-25).

**Reproduction**
```
MP4Box -add poc_06_add -new /tmp/out.mp4
```
